# Lip Print Identification System

This project is a web-based biometric identification system using lip print images and Convolutional Neural Network (CNN).

## Project Overview
This system detects and identifies individuals based on digital lip print images. The application integrates machine learning with web development for biometric classification.

## Technologies Used
- Python
- Flask
- PHP
- MySQL
- Convolutional Neural Network (CNN)

## Features
- Image upload and processing
- Automatic biometric classification
- Web-based interface
- Database integration
